# Roadmap — DevPulse

## Fase 0: investigación y especificación

- Inspeccionar el entorno.
- Investigar las interfaces de OpenCode.
- Validar la disponibilidad de métricas.
- Comparar tecnologías.
- Definir arquitectura.
- Documentar riesgos y decisiones.
- Crear la documentación inicial.

Estado: en curso.

## Fase 1: núcleo de la aplicación

- Crear la estructura del proyecto.
- Implementar configuración.
- Implementar almacenamiento local cuando corresponda.
- Crear los modelos internos.
- Establecer el sistema de registros.
- Implementar pruebas básicas.
- Crear una ventana inicial funcional.

## Fase 2: integración con OpenCode

- Implementar la detección de instancias.
- Consultar las fuentes de datos seleccionadas.
- Obtener sesiones y estadísticas.
- Normalizar los resultados.
- Manejar desconexiones.
- Validar la integración con OpenCode Desktop y CLI.

## Fase 3: widget funcional

- Implementar el modo compacto.
- Implementar el modo expandido.
- Mostrar métricas disponibles.
- Permitir seleccionar instancias y sesiones.
- Incorporar estados de conexión.
- Implementar la actualización adaptativa.

## Fase 4: personalización

- Crear la ventana de configuración.
- Implementar preferencias visuales.
- Guardar la posición y el tamaño.
- Implementar opciones de actualización.
- Configurar el inicio automático.
- Incorporar los mecanismos de ocultación y recuperación.

## Fase 5: calidad y distribución

- Completar pruebas.
- Evaluar rendimiento.
- Revisar seguridad.
- Corregir errores.
- Preparar el instalador.
- Probar la instalación y desinstalación.
- Actualizar documentación.
- Verificar que el proyecto se pueda construir siguiendo las instrucciones documentadas.

## Fase 6: evolución futura

Evaluar, sin implementarlas automáticamente:

- Integraciones con otros asistentes.
- Gráficos históricos.
- Estadísticas avanzadas.
- Alertas.
- Recomendaciones inteligentes.
- Sincronización opcional.
- Versiones para Linux y macOS.

Cada ampliación requerirá una especificación y una evaluación técnica propias.
